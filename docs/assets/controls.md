# Controls: third-party items

None. The controls code (`OpenFifa/Assets/Scripts/Core/Controls/`), its tests, the input actions asset (`OpenFifa/Assets/Settings/Input/OpenFifaControls.inputactions`) and `docs/CONTROLS.md` are original work.

The asset only uses Unity's Input System package (`com.unity.inputsystem`), which the project already depended on. The gamepad layout copies functional button conventions only. It has no EA names, art or glyphs (see the legal section of `docs/research/research_notes/Football game fidelity research/commentary_controls.md`).
